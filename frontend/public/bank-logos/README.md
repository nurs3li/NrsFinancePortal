# Banka logoları

Bu klasöre banka logo dosyalarını koyun. Uygulama otomatik olarak eşleştirir; dosya yoksa renkli kısaltma rozeti gösterilir.

## Dosya formatı

- **Format:** PNG veya SVG (tercihen şeffaf arka planlı PNG, ~64–128 px yükseklik)
- **İsimlendirme:** küçük harf, Türkçe karakter yok, boşluk yerine tire

## Sizin yapmanız gerekenler

1. Logoları (telif/izin sizde olacak şekilde) yukarıdaki isimlerle bu klasöre kaydedin.
2. `market-data-service` veya frontend’i yeniden başlatmanız gerekmez; sayfayı yenilemeniz yeterli.
3. Bana göndermeniz **şart değil** — dosyaları doğrudan projeye `frontend/public/bank-logos/` altına koymanız yeterli. İsterseniz zip ile paylaşıp repoya ekletebilirsiniz.

Ticari marka logoları için kurumunuzun kullanım koşullarına uyduğunuzdan emin olun.
